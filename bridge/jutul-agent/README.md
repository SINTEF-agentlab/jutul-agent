# jutul-agent is now Makker

jutul-agent has been renamed to [Makker](https://github.com/SINTEF-agentlab/makker),
an AI agent for computational science. Development continues there, under the
package name [`makker`](https://pypi.org/project/makker/).

## New installs

```sh
uv tool install makker
```

## Existing installs

Update as usual, with the Update button in the web UI or with
`uv tool upgrade jutul-agent`. This release then installs Makker and starts it:
your API keys, chats and workspaces are carried over, and the command is
`makker` from then on.

This is the last release under the old name.
