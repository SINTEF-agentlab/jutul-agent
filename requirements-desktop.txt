# Python requirements of the jutul-agent desktop app's backend
# (jutul_agent.interfaces.desktop), for an environment that runs only the

#
#   uv venv && uv pip install -r requirements-desktop.txt
#   uv pip install --no-deps -e .          # jutul-agent itself, without the web stack

#   - uvicorn      the HTTP/WebSocket server of `jutul-agent web`
#   - websockets   the web UI's reverse proxy to the kernel's plot server (a provider
#                  package may still bring it in; the desktop app never uses it)
# (`jutul-agent web` and its tests need the full install: `uv sync`.)
#
# The Electron runtime is the other half: see
# src/jutul_agent/interfaces/desktop/electron/package.json (pinned, with a lockfile).
